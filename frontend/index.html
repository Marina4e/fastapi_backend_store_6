API workers -

Worker-и налаштовуються в .env через API_WORKERS. Після зміни потрібен перезапуск: docker compose up --build -d.

1. Скинь залишок Для довгого тесту постав 20000 або 50000. Для перевірки зупинки постав 5.
2. Запусти тест Почни з пресету “Безпечний тест”. 1000 RPS краще перевіряти через Locust.
3. Дивись результат Якщо зʼявився 409 Conflict, товар закінчився і тест зупиниться.

RPS-тест з браузера

Це навчальний тест у браузері. Для справжнього benchmark використовуй Locust або tests/load_test.py. Тест купує товар product_id з ручної форми і списує по 1 одиниці за запит.

Статус idle
Ціль запитів 0
Відправлено 0
Завершено 0
Успішно 0
409 Conflict 0
Timeout/Error 0
Dropped 0
Фактичний RPS 0
In-flight 0
Якщо Dropped велике, браузер не встигає створити заданий RPS. Це не обов'язково помилка backend. Якщо тест закінчився за 1-2 секунди, найчастіша причина - малий залишок товару.
